This project started out as a way to simply create ammer 40K Army Lists.  Similar to BattleScribe.
This has morphed now into that, with an ultimate goal of having it able to track your lists performance.
   Which of course that requires multiple users ideally.  For an easier method of tracking performance, to enable better suggestions ultimately.
   This should hopefully take into account the players ability, ultimately I think that having a large user base would improve suggestions based on skill level.
Currently a C# front end with python parsing the army catalogs.
